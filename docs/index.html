Dynatrace Essentials — Study Notes

Original study notes for the Dynatrace University course Dynatrace Essentials (8 lessons + certificate exam). Each lesson file has: learning objectives, explained topics, a glossary, practical examples, the concepts the lesson's knowledge check tests, and review questions with answers.

# File Core topics
1 01-introduction-to-dynatrace Observability vs. monitoring, tool consolidation, OneAgent, ActiveGate, metrics/logs/traces, root cause analysis
2 02-dynatrace-architecture SaaS, Grail (MPP lakehouse), buckets & retention, Dynatrace Apps, OneAgent monitoring modes, platform support
3 03-dynatrace-topology Smartscape's 5 layers, hosts, processes & process groups, services, databases, applications, actions, detection rules, Apdex
4 04-digital-experience-monitoring RUM, auto-injection vs. agentless, Apdex thresholds, mobile RUM, user actions & sessions, synthetics, Session Replay
5 05-smart-organization Host groups, naming rules, tags, process group separation
6 06-exploring-problems Anomalies, static vs. baseline thresholds, problem types, root cause, analysis tools, Dynatrace Intelligence/Davis, problem settings
7 07-analyzing-observability-data Dashboards, DQL, Notebooks, Logs and Traces apps
8 08-extending-dynatrace Hub, extensions, cloud integrations, workflows, log ingestion, AppSec, OpenTelemetry, OneAgent SDK, bizevents, API, Kubernetes
— 09-cram-sheet-and-final-review All the numbers, comparisons, and a 40-question mixed review

How to use these notes

  1. Read a lesson file after (or instead of re-watching) the lesson.
  2. Cover the answers and do the review questions.
  3. Before the exam, work through file 09 cold, then revisit any lesson where you missed questions.

Note on sources: content is drawn from the course lessons. A few items flagged "supplementary" (e.g., extra DQL examples) go beyond the course text; verify them in the Dynatrace Playground or docs. Where the course itself was inconsistent, the notes call it out.
